# Support

- **Usage questions:** start a [discussion](https://github.com/sraodev/oli/discussions).
- **Reproducible bugs:** [open a bug report](https://github.com/sraodev/oli/issues/new?template=bug_report.yml).
- **Feature proposals:** check the [roadmap](ROADMAP.md), then [describe the gap](https://github.com/sraodev/oli/issues/new?template=feature_request.yml).
- **Security or unintended deletion:** use the private channel in [SECURITY.md](SECURITY.md), not a public issue.

Include your macOS version, architecture, Oli commit/version, command and a
minimal synthetic reproduction. Redact paths, usernames, tokens and personal
filenames. Do not paste the dashboard launch URL or a full home-directory scan.

If cleanup behaves unexpectedly, stop applying it and preserve the report
privately. Current deletion is permanent; maintainers cannot promise recovery.
Support is best-effort volunteer work, with no response-time guarantee.
