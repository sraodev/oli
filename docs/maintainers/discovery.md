# Useful discovery, not popularity promises

Oli should be easy to understand, try safely and contribute to. Discovery work
must reflect available functionality, not make the project look more complete
than it is.

## Maintainer checklist

- Keep the README's first screen focused on the problem, safety boundary and
  one working starting path. Separate merged source from published binaries.
- Use accurate repository topics and an original social preview. GitHub
  recommends a 1280 × 640 image below 1 MB; the supplied
  [social card](../assets/oli-social.png) must be uploaded through repository
  settings separately. Creating an asset does not set the repository preview.
  [GitHub preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)
- Keep bounded newcomer tasks and substantive help-wanted issues current.
  Clear labels help contributors find work; never label a destructive engine
  redesign as a beginner task.
  [GitHub contributor labels](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/encouraging-helpful-contributions-to-your-project-with-labels)
- Record a short synthetic-data demo after the demonstrated feature works.
  Share it in relevant communities with limitations, useful findings and a
  specific feedback request; no unsolicited bulk messages or copied branding.
- Measure views, unique visitors, clones, referrers and useful contributions
  over comparable periods. GitHub traffic has a limited reporting window;
  capture dated observations when needed. Stars are not a security/quality
  metric, and CTR needs impression data, not just repository views.
  [GitHub traffic guidance](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-traffic-to-a-repository)

No product telemetry, purchased stars, growth service or new hosting dependency
is needed for this work. Community-profile completeness is a contribution aid,
not certification that the cleanup engine is safe.
